# Intent

Build a reproducible Kotlin/Kafka Streams system that enriches purchases with the latest customer profile and aggregates customer summaries. The public proof is a real Kafka 4.3.1 end-to-end rate with output and state invariants, not an in-memory driver number.

Acceptance: implementation, tests, Docker, clean V2 baseline, security evidence, SBOM, green CI, and no P0/P1 review finding.
